Quick Start

1. Check an Address

cURL 
curl https://api.fidesorigin.com/api/v1/addresses/0x... \
  -H "Authorization: Bearer YOUR_API_KEY"

2. Install SDK

Shell 
npm install @fidesorigin/sdk

3. Integrate in Solidity

Solidity 0.8.26 
import "@fidesorigin/contracts/CompliantStableCoin.sol";

contract MyToken is CompliantStableCoin {
    constructor() CompliantStableCoin("MyToken", "MTK") {}
}

Core Concepts

On-Chain Risk Enforcement

Risk checks execute inside the transaction, not via external API calls. Deterministic, zero-latency, un-bypassable.

Risk Tiers

Five levels: UNKNOWN, LOW, MEDIUM, HIGH, CRITICAL. Each tier triggers different enforcement actions.

Policy Engine

Configurable rules per asset: max transaction amount, daily limits, sanctioned address blocking, KYC requirements.

Quarantine Vault

Suspicious transfers are held in escrow until manual review or automated criteria are met.
