# FidesOrigin 官网视觉提升方案（R10 · 多语言多主题全面评估）

- **日期**：2026-09-25
- **素材**：44 张全页截图——20 个核心页面 × 深/浅双主题 × 4 语言（en/cn/tw/jp）+ 4 张移动端（375px 深色），滚动触发 reveal 后采集
- **评估维度**：布局与信息层级 / 配色 / 字体排印 / 图标与插画 / 留白与间距 / 动效与交互 / 多语言一致性与本地化
- **基准**：世界一流 = Stripe（工程信任感）× a16z crypto（链上前沿感）× 高盛研报（金融排版纪律）

---

## 〇、总评

现有 "Ledger Precision" 设计体系（深海军蓝 × 青铜金、hairline 分隔、衬线大标题、等宽数据字）**基础极好**，工程一致性与无障碍水准已在同类产品前列。当前与世界一流水准的差距不在"体系"，而在**四个精修层面**：① CJK 标题衬线缺失导致非英语版本气质降级；② 动效与打印场景的完成度；③ 视觉框/插画的信息密度；④ 跨语言数据口径。以下按模块列出问题与可落地改进。

---

## 一、全局系统性（影响全站）

### G1｜中高｜CJK 标题衬线缺失——非英语版本气质降级的核心原因
- **问题**：英文大标题用 Fraunces 衬线（高级感的最大来源）；cn/tw/jp 标题的字体栈为 `Fraunces, "PingFang SC", …, "Songti SC", serif`——**PingFang/雅黑等无衬线黑体排在宋体之前**，中日韩标题实际渲染为黑体，与英文版的衬线气质断裂（对照 en-home 与 cn-home 标题区块差异明显）
- **改进方向**：标题字体栈内把 CJK 衬线前置：`Fraunces, "Songti SC", "Noto Serif SC", "Source Han Serif", serif`（仅标题栈；正文栈保持黑体）。可选进一步：自托管 Noto Serif SC 子集（next/font），彻底控制渲染
- **强化**：中文标题获得宋体的笔锋与衬线感，与 Fraunces 的"老式账本"气质对齐——这是**高级商务质感**在 CJK 市场的最大单点提升
- **优先级**：P0（性价比最高）

### G2｜中高｜reveal 动效的两个完成度缺口
- **问题**：① 快速甩轮时用户先看到空白、内容再逐个淡入（IO 触发即进入视口才开始 0.7s 过渡）；② 全站无 `@media print` 样式——**打印/导出 PDF 时所有 reveal 内容缺失**（金融合规站的高频场景：客户把 pricing/docs 打印存档）
- **改进方向**：① LegacyFx 的 IO 加 `rootMargin: "0px 0px 240px 0px"` 预热（进入视口前 240px 开始淡入，用户看到的是已落定的内容）；② 新增 `@media print { html.js .reveal:not(.visible) { opacity:1; transform:none } }` 与深色→浅色打印适配
- **强化**：滚动浏览"零等待感"= 高级产品的隐性品质；PDF 导出完整性 = 金融合规场景的专业可信
- **优先级**：P0（改动各一行）

### G3｜中｜跨语言演示数据口径不一
- **问题**：同一路径指标 en "20,645+"、cn "2,480+"、jp "35,486+"——同一产品各语言版本数据互相矛盾，损害可信度
- **改进方向**：统一为同一组真实数据（单一数据源注入字典），或刻意本地化时在页面注明口径；长期由 stats API 下发
- **强化**：金融产品的**数据自洽**是信任的底线
- **优先级**：P1

### G4｜低｜中西文混排间距
- **问题**：中文正文里英文术语（Chainalysis、ComplianceEngine）与中文之间无 1/4em 间隙（放大确认目前靠手写空格，覆盖不全处显拥挤）
- **改进方向**：长文容器启用 `text-autospace: normal`（渐进增强，Chromium 已支持）或正文审校时统一手写空格
- **优先级**：P2

## 二、首页（en/cn/tw/jp）

### M1｜中｜Features 视觉框信息密度不足
- **问题**：01 卡雷达图在 300px 高框内偏小、四周留白多；雷达图无轴标签/图例/扫描动效，"零装饰不承载信息"的标准下信息密度偏低
- **改进方向**：雷达图加维度轴标签（OFAC / Sanctions / Mixer）、中心扫描线旋转动画（尊重 reduced-motion）、四角坐标刻度；或改为"实时风险事件流"微图表
- **强化**：把装饰性插图变成**信息可视化**——正是"每个图形元素承载信息"品牌宣言的兑现，直接强化科技感与金融专业感
- **优先级**：P1

### M2｜低｜Workflow 三步连接线存在感弱
- **问题**：桌面 hairline 连接线 + 节点点亮动画在整页尺度下偏细弱
- **改进方向**：连接线加流动光点动画（数据沿管道流动的隐喻，`offset-path` 或渐变位移）；节点编号改青铜底色反白
- **强化**：数据流动的动态隐喻 = 区块链前沿氛围
- **优先级**：P2

### M3｜低｜首页 CTA 卡标题与 Hero 标题重复
- **问题**：移动端截图中底部 CTA 卡大标题与 hero 主标题同为 "Compliance, executed at block speed"（en 版），信息重复
- **改进方向**：CTA 卡标题改差异化文案（如 "Programmable compliance starts here"），与字典统一
- **强化**：叙事递进而非复读，成熟品牌的文案纪律
- **优先级**：P2

## 三、Pricing（en/cn/tw/jp）

### M4｜中｜对比表行交互与可读性精修
- **问题**：Feature comparison 表 11 行 × 4 列无行 hover、无奇偶行底色区分；长表格扫读时易串行
- **改进方向**：行 hover 高亮（--fio-hover-wash）+ 奇偶行 subtle 底色 + 首列吸左；"✓/—" 符号统一为图标字体避免字体渲染差异
- **强化**：长表格的扫读纪律是研报级排印的基本功
- **优先级**：P1

### M5｜低｜定价卡 ✗ 行视觉过弱
- **问题**：不含功能用 ✗ + 弱灰文字，深色下接近不可见（Starter 卡 "Market ✗" 等）
- **改进方向**：✗ 行保留但降透明度至设计预期（约 45%），并在 hover 卡片时轻微提亮；或改 "—" 破折号风格与对比表一致
- **强化**：克制的否定表达 = 高级感
- **优先级**：P2

## 五、Blog 文章页（en/cn/tw/jp）

### M7｜中｜文章 meta 行与导航闭环缺失
- **问题**：详情页无发布日期/作者/阅读时长/分类标签，也无上一篇/下一篇或"← 返回博客"导航（列表卡有日期，详情页反而没有）
- **改进方向**：标题下加 meta 行（date · author · category · read time）；文末加上/下一篇卡与返回链接
- **强化**：内容体系的完成度直接决定"内容营销是否可信"——机构级内容标配
- **优先级**：P1

## 六、Use Cases（en/cn/tw/jp）

### M8｜低｜Solution 区代码卡与文本的构图关联弱
- **问题**：左文右码构图成立，但代码卡底部斜体注释行紧贴卡缘、视觉重心偏散
- **改进方向**：代码卡加同款 fio-ticks 角标（呼应全站母题）；或 Solution 勾选行与代码行做视觉对齐（行高节奏一致）
- **优先级**：P2

## 七、Address Check（en/cn/tw/jp）

### M9｜低｜工具区下方留白过大
- **问题**：输入卡与 footer 之间约一屏空白
- **改进方向**：加"示例结果卡"（展示高危地址命中样例）或"数据来源徽标带"（OFAC / Chainalysis / Elliptic），复用 Trust 区素材
- **强化**：工具页的信任背书前置 = 金融专业感
- **优先级**：P2

## 八、多语言一致性与本地化

### L1｜✅ 良好｜结构模板化一致
- 4 语言区块顺序、组件、层级完全一致；hreflang/lang 属性构建期确定（无 FOUC）

### L2｜中｜日文文案疑似机翻痕迹
- **位置**：jp 首页 Features 区（"機械装置のような疑プロセッシング" 等表述生硬）
- **改进方向**：日文母语审校一轮；重点 Features/Trust/ Journey 长句
- **强化**：本地化品质 = 国际化品质的直接构成
- **优先级**：P1

### L3｜低｜CJK 行首标点与断行
- **复核结论**：行首标点 0 违规（浏览器 kinsoku 正常）；cn workflow 标题存在孤字断行（"…上链执行" 断出 "链执行"）
- **改进方向**：CJK 标题加 `text-wrap: balance`；该标题文案改为 "风控引擎 → 链上执行" 短句式
- **优先级**：P2

## 十、不建议动的部分（保持现状）

- 深色主色调与青铜金比例、hairline 分隔体系、fio-ticks 母题、等宽数据字、区块 7/9rem 节奏、页脚四列结构——均已达标，动它们反而破坏已建立的识别度
- 4 语言结构模板化差异为零——这是资产不是问题
