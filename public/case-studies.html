Stablecoin

Compliant Stablecoin Issuance

A Hong Kong-based stablecoin issuer needed to meet HKMA regulatory requirements while maintaining real-time AML screening across all transactions.

Challenge

Needed to satisfy HKMA's strict stablecoin licensing requirements including real-time AML screening, immutable audit trails, and 1:1 reserve attestations — all without introducing centralized infrastructure that would compromise the decentralized nature of the token.

Solution

FidesOrigin Guard pre-check engine integrated with compliant stablecoin smart contracts. Every mint, burn, and transfer is screened pre-broadcast. Policy engine configured with HKMA-specific rules: accredited investor checks, transaction limits, and OFAC screening.

Results

Passed HKMA regulatory review on first submission. Guard engine intercepted $2.3M in suspicious transaction volume before it ever hit the chain.

GuardConfig.sol Solidity 
// HKMA-compliant Guard configuration
function configureGuard() external {
    guard.setPolicy("stablecoin-hkma-v2");
    guard.enableOfacScreening(true);
    guard.setDailyLimit(1_000_000 * 1e6);
    guard.requireAccredited(true);
}

// previewTransaction — intercept before broadcast
function previewAndExecute(
    Transaction calldata tx
) external returns (Verdict) {
    Verdict v = guard.preview(tx);
    require(v != Verdict.BLOCK, "Non-compliant");
    return v;
}
RWA

RWA Tokenization Platform

An RWA issuance platform needed address-level compliance controls and investor qualification verification across multiple jurisdictions.

Challenge

Each tokenized asset required different compliance rules per jurisdiction — US accredited investors for some, EU MiCA for others, and local KYC requirements. Needed a solution that could deploy jurisdiction-specific policies without rewriting core contracts.

Solution

FidesOrigin's pluggable compliance module architecture with per-token policy assignment. KYC provider integration via oracle network. Each asset class gets its own policy module that can be hot-swapped without affecting other tokens.

Results

Full integration completed in 3 days. Platform now supports 5+ jurisdictions with independent policy enforcement per token. Zero contract redeployments since launch.

MultiPolicy.sol Solidity 
// Per-token jurisdiction policy
function assignPolicy(
    address token,
    string calldata jurisdiction,
    Policy calldata policy
) external {
    policies[token][jurisdiction] = policy;
    emit PolicyAssigned(token, jurisdiction);
}

// KYC oracle verification
function verifyInvestor(
    address investor,
    bytes32 merkleRoot
) external view returns (bool) {
    return kycOracle.isVerified(
        investor, merkleRoot
    );
}
Smart Wallet

Institutional-Grade Wallet

A Web2 payment platform expanding into crypto needed to add institutional-level risk controls to their wallet product without rebuilding from scratch.

Challenge

The platform's existing wallet infrastructure lacked any on-chain compliance layer. They needed to add real-time risk screening, sanctions checks, and transaction monitoring without disrupting the existing user experience or requiring months of engineering work.

Solution

FidesOrigin Guard engine embedded directly into the wallet's transaction flow via SDK. Zero changes to existing smart contracts — Guard intercepts at the application layer before transactions are signed and broadcast.

Results

Zero additional smart contract development required. Real-time risk interception with <50ms latency. Full regulatory audit trail generated automatically for every screened transaction.
