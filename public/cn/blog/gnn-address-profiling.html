博客 — AI/ML — 2026年8月

图神经网络
用于链上地址画像

为什么一次只看一个地址就像试图通过研究一栋建筑来理解一座城市。FidesOrigin 的图神经网络引擎看到的是整个图。

2026年1月，一个钱包地址出现在我们的监控系统中，风险评分为34——远低于80分的隔离阈值。从纸面上看，它没问题。该地址没有直接受到制裁打击，交易历史正常，没有明显的危险信号。传统的基于规则的系统会放行它。

但我们的图神经网络引擎还是标记了它。原因？这个地址距离一个已知的混币服务只有两跳，通过四个中间钱包连接，这四个钱包都在同一个24小时窗口内创建，并且来自同一资金来源。图神经网络不仅看到了这个地址——它看到了它的邻里。而这个邻里因为关联而被判定有罪。

三天后，该地址出现在 OFAC SDN 名单上。我们传统的规则引擎在官方更新前完全错过了它。图神经网络提前捕获了它。

这就是基于关系的风险分析的力量。也是为什么单地址画像在链上合规方面根本不足的原因。

单地址分析的局限

传统的链分析——为当今大多数合规 API 提供动力的那种——工作方式如下：从一个地址提取特征（余额、交易数量、年龄、已知关联），输入分类器，获得风险评分。本质上是一个表格机器学习问题。每个地址都是电子表格中的一行。模型永远看不到行之间的连接。

这种方法在区块链上有三个致命弱点：

1. 对手故意利用图结构。 复杂的攻击者不会使用一个钱包。他们使用五十个。他们通过中间地址剥离资金。他们使用隐私池、跨链桥和 DeFi 协议作为洗钱层。每个单独的地址看起来都是无辜的。模式才是信号。表格模型对此视而不见。

2. 新地址没有历史。 新创建的钱包有零笔交易、零余额和零特征。表格模型无从下手。但图神经网络可以从其连接推断风险：谁资助了它？它与谁交易？它属于哪个子图？图揭示了交易历史所隐藏的信息。

3. 风险是上下文相关的，不是固有的。 从受制裁实体接收资金的地址是有风险的。从合法交易所接收资金的同一地址则不是。风险是关系的属性，而不仅仅是地址本身。没有图就无法计算它。

Chainalysis 和 Elliptic 已经建立了庞大的标记地址数据库。他们的模型很复杂。但它们本质上仍然是表格化的："地址X具有属性Y，因此风险为Z。"图是事后考虑——一种可视化工具，而不是计算模型。

我们颠覆了这一点。在 FidesOrigin 中，图就是模型。

链上图：节点、边和特征

要了解图神经网络如何用于地址画像，我们先来定义我们正在操作的图。

节点是钱包地址和智能合约。每个节点都有一个特征向量，捕获其固有属性：交易数量、平均交易价值、首次交易以来的时间、余额历史方差、合约交互多样性等。我们从链上数据中提取每个节点约40个特征。

边代表交易。从地址A到地址B的边表示A向B发送了资金。边按交易价值、频率和时间接近度加权。同一对之间的多笔交易被聚合为具有复合权重的单一边。我们目前在以太坊、Base 和 Polygon 上跟踪约23亿条边。

节点标签来自多个来源：OFAC 制裁名单、交易所热/冷钱包标识、已知 DeFi 协议合约、钓鱼诈骗数据库以及我们自己的手动调查。只有极小比例的节点被标记——通常不到0.01%。挑战在于将这些标签通过图传播到未标记节点。

图的规模：我们的生产图目前包含约1.8亿个节点和约23亿条边，从以太坊主网、Base 和 Polygon 实时更新。完整图对于单个 GPU 来说太大，因此我们使用子图采样和小批量训练。

从图到风险评分：图神经网络的工作原理

图神经网络基于一个简单但强大的理念运作：节点的表示应该是其自身特征和其邻居表示的函数。信息通过图传播，一次一跳，网络的每一层允许模型看到邻域更远的地方。

我们使用受GAT（图注意力网络）启发的注意力机制的GraphSAGE（图采样与聚合）架构。以下是这种组合适用于我们的用例的原因：

GraphSAGE专为归纳学习而设计——它可以为训练期间从未见过的节点生成嵌入。这对于链上合规至关重要，因为新地址每秒都在创建。我们无法每次出现新钱包时都重新训练模型。GraphSAGE 的采样方法让我们能够使用仅本地邻域即时计算新节点的嵌入。

注意力机制（来自 GAT）让模型学习哪些邻居最重要。并非所有连接都平等。来自随机地址的10美元转账是噪音。来自已知交易所的50万美元转账是信号。注意力权重自动从数据中学习，无需手工规则。

前向传播的工作方式如下。对于每个节点，我们采样固定数量的邻居（我们使用每跳25个邻居的2跳）。我们使用学习的聚合函数聚合邻居特征——在我们的情况下，来自注意力机制的学习加权平均。然后我们将聚合的邻居表示与节点自身的特征连接起来，并通过非线性变换传递。对L层重复此操作（我们使用L=3），你就有一个编码L跳邻域信息的节点嵌入。

图神经网络前向传播（简化版） Python / PyTorch Geometric 
import torch
import torch.nn.functional as F
from torch_geometric.nn import SAGEConv, GATConv

class RiskGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = GATConv(hidden_channels, hidden_channels, heads=4, concat=False)
        self.conv3 = SAGEConv(hidden_channels, out_channels)
        self.classifier = torch.nn.Linear(out_channels, 3)  # ALLOW, WARN, BLOCK

    def forward(self, x, edge_index, edge_attr):
        # Layer 1: SAGE aggregation, 1-hop neighbors
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 2: GAT with attention, 2-hop neighbors
        x = self.conv2(x, edge_index, edge_attr)
        x = F.elu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 3: SAGE aggregation, 3-hop neighbors
        x = self.conv3(x, edge_index)

        # Risk classification
        return self.classifier(x)

输出是三分类（允许、警告、拦截）加上0到100的连续风险评分。风险评分使用校准的 softmax 从 logits 导出——我们在保留验证集上使用温度缩放来确保评分在概率上有意义。

三种图神经网络驱动的检测模式

图神经网络不仅仅产生风险评分。它使表格方法无法实现的特定检测能力成为可能。

1. 社区发现：映射混币网络

混币服务和 tumbler 是链上合规的阿喀琉斯之踵。它们通过聚合来自多个来源的输入并将其重新分配到多个输出，故意混淆资金流动。从单地址角度来看，混币输出地址看起来是从"合法"服务接收资金。从图角度来看，它是一个具有特定拓扑特征的密集连接集群中的节点。

我们的图神经网络学会识别这些特征：异常高的入度和出度、与其他混币相关地址之间的短平均路径长度、时间聚类（狭窄时间窗口内的许多相关交易）和价值同质性（进出金额相似）。模型不需要知道混币器的名称。它从图结构中学习模式。

在生产环境中，这使我们能够识别出14个任何公共数据库中都没有的未知混币服务。其中之一在被检测到之前已处理了超过4000万美元的交易量。

2. 异常检测：发现女巫攻击

链上背景下的女巫攻击涉及创建许多化名身份（钱包）来操纵协议——用于空投农场、治理操纵或洗盘交易。每个单独的钱包看起来正常。但图神经网络看到了创建模式：数十个来自同一来源的钱包，具有相似的交易模式，从不相互交互（以避免明显的聚类），但都在狭窄的时间窗口内通过共同的 DeFi 协议连接。

图神经网络计算所有节点的嵌入。然后我们对这些嵌入运行 DBSCAN 聚类。正常用户形成分散的、低密度的聚类。女巫网络形成紧密的、高密度的聚类，与合法用户明显分离。聚类是无监督的——我们不需要标记的女巫数据。图结构就是信号。

我们在2026年3月检测到一个针对空投活动的3200个钱包的女巫农场。该农场旨在规避简单启发式规则（每个钱包都有"独特"的资金来源，通过剥离链）。图神经网络在嵌入空间中捕获了共同的结构特征。

3. 风险传播：传染如何扩散

也许图神经网络最强大的能力是风险传播。当一个新地址被添加到 OFAC SDN 名单时，图神经网络不仅仅标记该地址。它为3跳邻域内的每个节点重新计算风险评分。以前低风险的地址可能因为现在直接或间接连接到受制裁实体而升级为高风险。

这不是简单的传递闭包。图神经网络学习风险如何传播：来自受制裁地址的1000万美元转账是高风险。通过中间交易所三跳之外的50美元转账风险较低。GAT 层中的注意力权重从训练数据中学习这些细微的传播规则。

当 OFAC 在2026年4月更新制裁名单时，我们的系统在5分钟内为210万个地址重新计算了风险评分。其中，847个地址跨越了隔离阈值，并自动在风险注册表中被标记。基于规则的系统只会捕获直接列出的地址——23个。

实时特征工程管道

模型的好坏取决于供给它的数据管道。我们的管道在连续循环中运行：

数据摄取：我们通过 WebSocket 订阅来自多个 RPC 提供商的以太坊、Base 和 Polygon 的实时数据。新交易通过 Kafka 缓冲，按区块号分区。我们在高峰期每秒处理约15,000笔交易。

图构建：每笔新交易都会实时更新图。我们在分布式键值存储（ScyllaDB）中维护图，每个节点都有邻接表。边权重在插入时计算：按发送者历史平均值归一化的价值、时间衰减因子和代币类型（稳定币比 meme 币的风险权重更高）。

图神经网络推理：每5分钟，我们触发批量推理作业。我们识别自上次运行以来所有已更改的节点（新交易、更新标签或手动注释）及其3跳邻域。我们使用在 GPU 集群上运行的生产图神经网络模型计算该子图的嵌入。平均推理时间：50万个节点的批次约90秒。

标签生成：图神经网络输出风险评分和分类。我们应用后处理规则：拦截分类且置信度>0.95的地址被标记为立即行动。警告分类且置信度>0.8的地址排队等待人工审查。其他所有内容都与其评分一起存储在风险数据库中。

预言机推送：更新的风险评分被格式化为 Merkle 树并推送到链上预言机合约。然后预言机更新 RiskRegistry，使新评分可用于守卫和合规引擎。从交易摄取到链上可用的总延迟：<7分钟。

性能与准确性

让我们谈谈数字。我们已经在生产环境中运行图神经网络8个月了。以下是最重要的指标：

制裁地址识别：在50,000个地址的保留测试集上（包括1,200个已知制裁地址），图神经网络在识别制裁地址方面达到了96.3%的精确率和94.7%的召回率。误报率为0.8%——意味着99.2%的非制裁地址被正确分类为干净。这显著优于我们之前的表格 XGBoost 模型，后者在同一数据集上达到了89.1%的精确率和82.4%的召回率。

混币器检测：在手动整理的8,500个混币相关地址数据集上，图神经网络达到了91.2%的 F1 分数。关键优势在于检测未知混币器——训练标签中不存在的地址。在这里，图神经网络的归纳能力大放异彩。它通过识别结构模式而不是记忆地址来推广到新的混币器。

推理延迟：对于单地址查询（我们守卫集成的常见情况），GPU 上的嵌入计算约需12毫秒，CPU 回退约需45毫秒。对于批量推理（50万个节点），完整管道约需90秒完成。5分钟的更新间隔意味着链上风险数据永远不会超过5分钟的陈旧度。

训练：我们每月在完整图上使用半监督学习重新训练模型。模型在标记节点（制裁、交易所、已知不良行为者）上训练，并使用图结构将标签传播到未标记节点。在4个 A100 GPU 上训练约需6小时。

为什么这对合规很重要

链上金融的监管格局正在硬化。欧盟的 MiCA 框架要求"能够检测可疑模式的交易监控系统"。香港的稳定币许可制度要求"持续监控客户交易"。美国财政部明确表示，合规计划必须"合理设计"以防止制裁违规——而"我们不知道"不是辩护理由。

仅针对静态列表检查地址的合规系统不是"合理设计"的。它是一个打钩清单。监管机构知道这一点。他们要求行为分析、模式检测、关系映射。图神经网络正好提供了这些——而且是以监管机构可以独立验证的审计跟踪形式。

每个图神经网络推理结果都被记录：输入特征、采样的图邻域、模型版本、输出评分和时间戳。这不是做出不透明决策的黑盒 AI。它是一个透明的、可复现的风险评估，碰巧使用神经网络进行计算。

更重要的是，图神经网络实现了主动合规。与其对制裁名单更新做出反应（这可能比实际活动滞后数天或数周），图神经网络在它们出现在官方名单之前就识别出风险模式。我们在1月份标记的地址——距离混币器两跳，通过可疑的钱包创建模式连接——三天后出现在 OFAC 名单上。图神经网络没有水晶球。它有图。

对于稳定币发行方、DeFi 协议和 RWA 平台，这意味着一个不仅让你免于麻烦——而且让你领先于麻烦的合规层。在一个监管行动可能关乎存亡的行业中，领先是唯一安全的地方。
