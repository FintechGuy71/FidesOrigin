稳定币

GlobalPay USD — MiCA 合规稳定币

GlobalPay 推出了一款面向欧盟市场的欧元背书的稳定币。他们需要实时 OFAC 筛查、MiCA 储备证明和自动化 KYC 验证——且不引入中心化基础设施。

FidesOrigin 的 CompliantStableCoin 基础合约在每次铸造、销毁和转账时提供确定性筛查。策略引擎配置了 MiCA 专用规则：1:1 储备要求、每日交易限额和合格投资者检查。

RWA

RealT — 代币化房地产合规

RealT 在多个司法管辖区将房地产代币化。每处房产有不同的投资者要求：部分仅限美国合格投资者，部分需符合欧盟 MiCA，还有司法管辖区特定的 KYC。

FidesOrigin 的多策略支持允许 RealT 为每种代币分配不同的合规规则。基于默克尔树的风险注册表实现了隐私保护验证，无需在链上暴露投资者数据。

    address token,
    Policy calldata policy
) external {
    policies[token] = policy;

}
智能钱包

SafeFlow — 具备合规功能的账户抽象

SafeFlow 为机构用户构建了一个 ERC-4337 智能钱包。他们需要在 bundler 提交前对每个 userOp 进行筛查——且不增加延迟或影响账户抽象流程。

通过在验证阶段集成 FidesOrigin，SafeFlow 在 bundler 看到 userOp 之前筛查所有目标地址和调用数据。集成仅增加了不到 10ms 的验证时间。

// Validate before bundler acceptance
function validateUserOp(
    UserOperation calldata userOp
) external override returns (uint256) {
    require(
        fides.isCompliant(userOp),
        "Non-compliant userOp"
    );
    return _validateSignature(userOp);
}
