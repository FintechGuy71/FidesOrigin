四大核心差异

FidesOrigin 的独特之处

同属一个行业，但处于技术栈的不同层级。四个维度上，架构与时机的差异造就了截然不同的结果。

时机

实时拦截

Chainalysis 和 Elliptic 在交易确认之后进行分析以供调查。FidesOrigin 在执行之前进行评估并阻止，防患于未然，而非事后记录。

执行层

智能合约原生

传统工具存在于链外，为人工决策提供数据。FidesOrigin 将执法逻辑嵌入智能合约，使合规具有确定性且不可绕过。

定价

按笔收费

年度 SaaS订阅（5万–50万美元）将小型参与者拒之门外。按笔收费（10–50美分）随用量扩展，无需预付承诺。

开放性

MIT 许可，已审计

闭源合规存在不透明风险。FidesOrigin 完整源码采用 MIT 许可，并经过多轮第三方审计。监管机构和审计方可逐行验证。

用例对比

各方案适用场景

没有工具是万能的。正确的选择取决于您的风险模型、预算和监管要求。

01

稳定币发行方需要香港金管局牌照

一家香港稳定币发行方必须向香港金管局审查员证明其实时反洗钱筛查、不可篡改的审计追踪以及自动化的赎回控制能力。

FidesOrigin

可插拔合规模块直接嵌入稳定币合约。每笔转账在 50毫秒内完成筛查。所有决策在链上不可篡改地记录。审计追踪是加密的，而非数据库导出。已有发行方使用 FidesOrigin 获得香港金管局原则性批准。

Chainalysis / Elliptic

通过 API 提供风险数据。发行方必须构建定制集成，将审计日志存储在数据库中，并向监管机构证明每次筛查调用确实被执行。没有链上执法意味着合规效果取决于集成代码的质量。

02

DeFi 协议希望吸引机构资金

一个链上借贷协议需要吸引要求合规保障的机构流动性提供者，才愿意存入资金。

FidesOrigin

在协议层面集成 Guard 模块。每笔借入/借出/清算都经过策略检查。机构流动性提供者可以在链上验证合规逻辑。没有黑箱 — 策略即代码。

Chainalysis / Elliptic

协议在 UI 层面查询风险 API。 sophisticated 用户可以绕过 UI，直接与智能合约交互，永远不会触发风险检查。合规作秀，而非执法。

决策框架

何时选择什么

客观建议：每种方案都有其理想的应用场景。

当您需要以下能力时，选择 FidesOrigin：

  • ✓ 实时交易拦截（不仅是检测）
  • ✓ 面向监管机构的链上不可篡改审计追踪
  • ✓ 按笔收费定价（无年度承诺）
  • ✓ 可审计和修改的开源基础设施
  • ✓ 稳定币或 RWA 代币化需要牌照级合规
  • ✓ 零确认内存池风险拦截

当您需要以下能力时，选择 Chainalysis / Elliptic：

  • ✓ 面向执法机构的调查取证
  • ✓ 历史交易追踪和图谱分析
  • ✓ 威胁情报和暗网监控
  • ✓ 拥有专属合规团队的大型企业
  • ✓ 预算支持 10万美元以上的年度 SaaS订阅

许多组织同时使用两者：Chainalysis/Elliptic 用于调查和情报，FidesOrigin 用于实时执法。
