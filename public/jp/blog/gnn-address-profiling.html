ブログ — AI/ML — 2026年8月

グラフニューラルネットワーク
によるオンチェーンアドレスプロファイリング

なぜ一度に1つのアドレスしか見ないのは、1つの建物を研究して都市を理解しようとするようなものなのか。FidesOrigin の GNN エンジンは、グラフ全体を見ています。

2026年1月、あるウォレットアドレスが当社の監視システムにリスクスコア34で出現しました——80ポイントの隔離閾値を大きく下回るスコアです。表向きは問題ありませんでした。このアドレスには直接的な制裁ヒットはなく、通常の取引履歴があり、明らかなレッドフラグもありませんでした。従来のルールベースのシステムなら通過していたでしょう。

しかし、当社のグラフニューラルネットワーク（GNN）エンジンはそれをフラグ付けしました。理由？このアドレスは既知のミキシングサービスから2ホップの距離にあり、24時間以内に同じソースから資金提供された4つの中間ウォレットを介して接続されていました。GNN はアドレスそのものだけでなく——その近隣を見ていました。そしてその近隣は、連座で罪があると判定されました。

3日後、そのアドレスは OFAC SDN リストに掲載されました。当社の従来のルールエンジンは、公式更新まで完全に見落としていました。GNN は早期に捕捉していました。

これが関係ベースのリスク分析の力です。そして、単一アドレスのプロファイリングがオンチェーンコンプライアンスにとって根本的に不十分である理由です。

単一アドレス分析の限界

従来のチェーン分析——現在のほとんどのコンプライアンス API を支えるもの——は次のように動作します：アドレスから特徴を抽出（残高、取引数、年齢、既知の関連）、分類器に入力し、リスクスコアを取得します。本質的には表形式の機械学習問題です。各アドレスはスプレッドシートの1行です。モデルは行間の接続を決して見ません。

このアプローチにはブロックチェーン上で3つの致命的な弱点があります：

1. 敵対者はグラフ構造を意図的に悪用する。 洗練された攻撃者は1つのウォレットを使いません。50個使います。中間アドレスを通じて資金を剥離します。プライバシープール、クロスチェーンブリッジ、DeFi プロトコルをマネーロンダリング層として使用します。各個別のアドレスは無害に見えます。パターンがシグナルです。表形式のモデルはこれに対して盲目です。

2. 新しいアドレスには履歴がない。 新しく作成されたウォレットは取引ゼロ、残高ゼロ、特徴ゼロです。表形式のモデルには何も扱えません。しかし、GNN は接続からリスクを推論できます：誰が資金提供したのか？誰と取引しているのか？どのサブグラフに属しているのか？グラフは、取引履歴が隠しているものを明らかにします。

3. リスクは文脈に依存し、固有ではない。 制裁対象エンティティから資金を受け取るアドレスはリスクがあります。同じアドレスが合法的な取引所から資金を受け取る場合はリスクではありません。リスクは関係の属性であり、アドレス自体だけではありません。グラフなしでは計算できません。

Chainalysis と Elliptic は巨大なラベル付きアドレスデータベースを構築しました。彼らのモデルは高度です。しかし、本質的には依然として表形式的です：「アドレスXに属性Yがあるため、リスクはZ」。グラフは後付けの考慮事項——可視化ツールであり、計算モデルではありません。

私たちはこれを覆しました。FidesOrigin では、グラフがモデルそのものです。

オンチェーングラフ：ノード、エッジ、特徴

GNN がアドレスプロファイリングにどのように機能するかを理解するために、私たちが操作しているグラフを定義しましょう。

ノードはウォレットアドレスとスマートコントラクトです。各ノードは固有の属性を捉える特徴ベクトルを持っています：取引数、平均取引値、最初の取引からの経過時間、残高履歴の分散、コントラクトインタラクションの多様性など。オンチェーンデータから各ノードあたり約40の特徴を抽出しています。

エッジは取引を表します。アドレスAからアドレスBへのエッジは、AがBに資金を送ったことを意味します。エッジは取引価値、頻度、時間的近接性で重み付けされます。同じペア間の複数の取引は、複合的な重みを持つ単一のエッジに集約されます。現在、Ethereum、Base、Polygon で約23億のエッジを追跡しています。

ノードラベルは複数のソースから得られます：OFAC 制裁リスト、取引所のホット/コールドウォレット指定、既知の DeFi プロトコルコントラクト、フィッシング詐欺データベース、および当社独自の手動調査。ラベル付けされたノードの割合は非常に小さく——通常0.01%未満です。課題は、これらのラベルをグラフを通じて未ラベルのノードに伝播させることです。

グラフの規模：当社の本番グラフには現在約1.8億のノードと約23億のエッジが含まれており、Ethereum メインネット、Base、Polygon からリアルタイムで更新されています。完全なグラフは単一の GPU には大きすぎるため、サブグラフサンプリングとミニバッチ学習を使用しています。

グラフからリスクスコアへ：GNN の仕組み

グラフニューラルネットワークは、シンプルだが強力なアイデアに基づいて動作します：ノードの表現は、自身の特徴と隣接ノードの表現の関数であるべきです。情報はグラフを通じて伝播し、ネットワークの各レイヤーでモデルは近隣をさらに遠くまで見ることができます。

私たちは、GAT（グラフアテンションネットワーク）にインスパイアされたアテンションメカニズムを備えたGraphSAGE（グラフサンプリングとアグリゲーション）アーキテクチャを使用しています。この組み合わせが当社のユースケースに適する理由は以下の通りです：

GraphSAGEは帰納学習のために設計されています——学習中に見たことがないノードの埋め込みを生成できます。これは、毎秒新しいアドレスが作成されるオンチェーンコンプライアンスにとって重要です。新しいウォレットが出現するたびにモデルを再学習することはできません。GraphSAGE のサンプリングアプローチにより、ローカル近隣のみを使用して新しいノードの埋め込みをオンデマンドで計算できます。

アテンションメカニズム（GAT から）は、どの隣接ノードが最も重要かをモデルが学習できるようにします。すべての接続が等しいわけではありません。ランダムなアドレスからの10ドルの送金はノイズです。既知の取引所からの50万ドルの送金はシグナルです。アテンションウェイトは、手作りのルールなしにデータから自動的に学習されます。

フォワードパスは次のように動作します。各ノードについて、固定数の隣接ノードをサンプリングします（当社はホップあたり25の隣接ノードで2ホップを使用）。学習されたアグリゲーション関数を使用して隣接ノードの特徴をアグリゲートします——当社の場合、アテンションメカニズムからの学習重み付き平均です。次に、アグリゲートされた隣接ノードの表現をノード自身の特徴と連結し、非線形変換を通します。これをLレイヤー（当社はL=3）繰り返すと、Lホップの近隣情報をエンコードしたノード埋め込みが得られます。

GNN フォワードパス（簡略版） Python / PyTorch Geometric 
import torch
import torch.nn.functional as F
from torch_geometric.nn import SAGEConv, GATConv

class RiskGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = GATConv(hidden_channels, hidden_channels, heads=4, concat=False)
        self.conv3 = SAGEConv(hidden_channels, out_channels)
        self.classifier = torch.nn.Linear(out_channels, 3)  # ALLOW, WARN, BLOCK

    def forward(self, x, edge_index, edge_attr):
        # Layer 1: SAGE aggregation, 1-hop neighbors
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 2: GAT with attention, 2-hop neighbors
        x = self.conv2(x, edge_index, edge_attr)
        x = F.elu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 3: SAGE aggregation, 3-hop neighbors
        x = self.conv3(x, edge_index)

        # Risk classification
        return self.classifier(x)

出力は3値分類（ALLOW、WARN、BLOCK）に加えて、0から100までの連続的なリスクスコアです。リスクスコアは、保留検証セット上で温度スケーリングを使用してキャリブレーションされた softmax を使用して logits から導出されます——スコアが確率的に意味のあるものであることを確認します。

3つの GNN 駆動検出パターン

GNN はリスクスコアを生成するだけでなく、表形式の方法では不可能な特定の検出機能を実現します。

1. コミュニティ発見：ミキシングネットワークのマッピング

ミキシングサービスとタンブラーは、オンチェーンコンプライアンスのアキレス腱です。多くのソースからのインプットを集約し、多くのアウトプットに再分配することで、資金の流れを意図的に難読化します。単一アドレスの観点からは、ミキサーのアウトプットアドレスは「合法的」なサービスから資金を受け取ったように見えます。グラフの観点からは、特定のトポロジカルシグネチャを持つ密に接続されたクラスターのノードです。

当社の GNN はこれらのシグネチャを認識することを学習します：異常に高い入次数と出次数、他のミキサー関連アドレスへの短い平均パス長、時間的クラスタリング（狭い時間枠内の多くの関連取引）、および価値の均質性（入出金額の類似性）。モデルはミキサーの名前を知る必要はありません。グラフ構造からパターンを学習します。

本番環境では、これにより14個の既知のデータベースにない未知のミキシングサービスを特定できました。その1つは、検出される前に4,000万ドル以上の取引量を処理していました。

2. 異常検出：シビル攻撃の検出

オンチェーンの文脈でのシビル攻撃は、多くの偽名アイデンティティ（ウォレット）を作成してプロトコルを操作することを含みます——エアドロップファーミング、ガバナンス操作、またはウォッシュトレードのために。各個別のウォレットは正常に見えます。しかし、GNN は作成パターンを見ます：同じソースから資金提供された数十のウォレット、類似した取引パターン、互いにやり取りしない（明らかなクラスタリングを避けるため）、しかし狭い時間枠内に共通の DeFi プロトコルを介してすべて接続されています。

GNN はすべてのノードの埋め込みを計算します。次に、これらの埋め込みに DBSCAN クラスタリングを実行します。通常のユーザーは分散した低密度クラスターを形成します。シビルネットワークは、合法的なユーザーから明確に分離された、密な高密度クラスターを形成します。クラスタリングは教師なしです——ラベル付きのシビルデータは必要ありません。グラフ構造がシグナルです。

2026年3月にエアドロップキャンペーンを標的とした3,200ウォレットのシビルファームを検出しました。このファームは単純なヒューリスティックを回避するように設計されていました（各ウォレットはピーリングチェーンを介して「独自」の資金源を持っていました）。GNN は埋め込み空間で共通の構造的シグネチャを捉えました。

3. リスク伝播：感染がどのように広がるか

おそらく最も強力な GNN の能力はリスク伝播です。新しいアドレスが OFAC SDN リストに追加されると、GNN はそのアドレスだけでなく、その3ホップ近隣内のすべてのノードのリスクスコアを再計算します。以前は低リスクだったアドレスが、現在は制裁対象エンティティに直接または間接的に接続されているため、リスクが高まる可能性があります。

これは単純な推移的閉包ではありません。GNN はリスクがどのように伝播するかを学習します：制裁対象アドレスからの1,000万ドルの送金は高リスクです。中間取引所を介して3ホップ離れた50ドルの送金は低リスクです。GAT レイヤーのアテンションウェイトは、学習データからこれらの微妙な伝播ルールを学習します。

OFAC が2026年4月に制裁リストを更新したとき、当社のシステムは5分以内に210万のアドレスのリスクスコアを再計算しました。そのうち、847のアドレスが隔離閾値を超え、リスクレジストリで自動的にフラグ付けされました。ルールベースのシステムは、直接リストされた23のアドレスのみを捉えていたでしょう。

リアルタイム特徴エンジニアリングパイプライン

モデルの質は、それに供給するデータパイプラインの質によって決まります。当社のパイプラインは継続的ループで動作します：

データ取り込み：複数の RPC プロバイダーから Ethereum、Base、Polygon の WebSocket フィードを購読します。新しい取引は Kafka でバッファリングされ、ブロック番号でパーティション分割されます。ピーク時には毎秒約15,000の取引を処理します。

グラフ構築：すべての新しい取引がリアルタイムでグラフを更新します。分散キーバリューストア（ScyllaDB）で隣接リストを持つグラフを維持しています。エッジの重みは挿入時に計算されます：送信者の履歴平均で正規化された価値、時間減衰係数、トークンタイプ（リスク目的ではステーブルコインがミームコインより重み付けされます）。

GNN 推論：5分ごとにバッチ推論ジョブをトリガーします。前回の実行以降に変更されたすべてのノード（新しい取引、更新されたラベル、または手動注釈）とその3ホップ近隣を特定します。GPU クラスターで実行されている本番 GNN モデルを使用して、このサブグラフの埋め込みを計算します。平均推論時間：500,000ノードのバッチで約90秒。

ラベル生成：GNN はリスクスコアと分類を出力します。後処理ルールを適用します：BLOCK 分類で信頼度>0.95のアドレスは即時アクションのためにフラグ付けされます。WARN 分類で信頼度>0.8のアドレスは人間のレビューのためにキューに入れられます。それ以外のすべては、スコアとともにリスクデータベースに格納されます。

オラクルプッシュ：更新されたリスクスコアは Merkle ツリーにフォーマットされ、オンチェーンオラクルコントラクトにプッシュされます。次に、オラクルは RiskRegistry を更新し、ガードとコンプライアンスエンジンが新しいスコアを使用できるようにします。取引取り込みからオンチェーン利用可能になるまでの総レイテンシ：<7分。

パフォーマンスと精度

数字について話しましょう。GNN は本番環境で8ヶ月間実行されています。重要な指標は以下の通りです：

制裁アドレスの特定：50,000のアドレスのホールドアウトテストセット（1,200の既知の制裁対象アドレスを含む）で、GNN は制裁対象アドレスの特定において96.3%の適合率と94.7%の再現率を達成しました。誤検出率は0.8%——99.2%の非制裁対象アドレスが正しくクリーンとして分類されました。これは、同じデータセットで89.1%の適合率と82.4%の再現率を達成した以前の表形式 XGBoost モデルに対して大幅な改善です。

ミキサー検出：手動でキュレーションされた8,500のミキサー関連アドレスデータセットで、GNN は91.2%の F1 スコアを達成しました。重要な利点は未知のミキサーを検出する能力です——トレーニングラベルに存在しないアドレス。ここで GNN の帰納能力が輝きます。構造パターンを認識することで、新しいミキサーに一般化します。

推論レイテンシ：単一アドレスクエリ（ガード統合の一般的なケース）では、GPU での埋め込み計算に約12ミリ秒、CPU フォールバックで約45ミリ秒かかります。バッチ推論（500,000ノード）では、完全なパイプラインが約90秒で完了します。5分の更新間隔により、オンチェーンリスクデータは5分以上古くなることはありません。

学習：完全なグラフで半教師あり学習を使用して毎月モデルを再学習します。モデルはラベル付きノード（制裁、取引所、既知の不良行為者）で学習され、グラフ構造を使用して未ラベルのノードにラベルを伝播します。4x A100 GPU での学習には約6時間かかります。

なぜこれがコンプライアンスに重要か

オンチェーン金融の規制環境は厳しくなっています。EU の MiCA フレームワークは「疑わしいパターンを検出できる取引監視システム」を要求しています。香港のステーブルコインライセンス制度は「継続的な顧客取引の監視」を義務付けています。米国財務省は、コンプライアンスプログラムが制裁違反を防ぐために「合理的に設計」されていなければならないことを明確にしています——そして「知らなかった」は弁護になりません。

静的なリストに対してアドレスをチェックするだけのコンプライアンスシステムは「合理的に設計」されていません。チェックリストです。規制当局はこれを知っています。彼らは行動分析、パターン検出、関係マッピングを求めています。GNN はまさにこれを提供します——そして規制当局が独立して検証できる監査証跡の形で。

すべての GNN 推論結果は記録されます：入力特徴、サンプリングされたグラフ近隣、モデルバージョン、出力スコア、タイムスタンプ。これは不透明な決定を下すブラックボックス AI ではありません。ニューラルネットワークを使用して計算される、透明で再現可能なリスク評価です。

さらに重要なことに、GNN はプロアクティブなコンプライアンスを可能にします。制裁リストの更新に反応するのではなく（これは実際の活動より数日から数週間遅れることがあります）、GNN は公式リストに掲載される前にリスクパターンを特定します。1月にフラグ付けしたアドレス——ミキサーから2ホップ、疑わしいウォレット作成パターンで接続——は3日後に OFAC リストに掲載されました。GNN に水晶球はありません。グラフがあります。

ステーブルコイン発行体、DeFi プロトコル、RWA プラットフォームにとって、これはトラブルを回避するだけでなく——トラブルより先回りするコンプライアンスレイヤーを意味します。そして、規制措置が存亡に関わる可能性のある業界で、先回りすることだけが安全な場所です。
