ステーブルコイン

GlobalPay USD — MiCA 対応ステーブルコイン

GlobalPay は EU 市場向けにユーロ建てのステーブルコインをローンチしました。リアルタイムの OFAC スクリーニング、MiCA 準備金証明、自動化された KYC 検証が必要でした——かつ、中央集権的なインフラを導入することなく。

FidesOrigin の CompliantStableCoin ベースコントラクトは、すべての鋳造、焼却、転送時に決定論的なスクリーニングを提供します。ポリシーエンジンは MiCA 特有のルールで設定されています：1:1 の準備金要件、日次取引限度、適格投資家チェックです。

RWA

RealT — トークン化不動産のコンプライアンス

RealT は複数の司法管轄区で不動産をトークン化しています。各物件には異なる投資家要件があります：一部は米国適格投資家のみ、一部は EU MiCA 対応、その他は司法管轄区固有の KYC です。

FidesOrigin のマルチポリシー対応により、RealT はトークンごとに異なるコンプライアンスルールを割り当てることができます。マークルベースのリスクレジストリにより、投資家データをオンチェーンに露出することなくプライバシー保護検証が可能です。

スマートウォレット

SafeFlow — コンプライアンス付きアカウント抽象化

SafeFlow は機関投資家向けに ERC-4337 スマートウォレットを構築しました。バンドラー提出前にすべての userOp をスクリーニングする必要がありました——遅延を増やしたり、アカウント抽象化の流れを損なったりすることなく。

FidesOrigin を検証フェーズに統合することで、SafeFlow はバンドラーが userOp を認識する前にすべての宛先アドレスと呼び出しデータをスクリーニングします。統合による検証時間の増加は 10ms 未満です。

// Validate before bundler acceptance
function validateUserOp(
    UserOperation calldata userOp
) external override returns (uint256) {
    require(
        fides.isCompliant(userOp),
        "Non-compliant userOp"
    );
