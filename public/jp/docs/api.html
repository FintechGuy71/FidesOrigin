API リファレンス

オンチェーン・コンプライアンスとリスク評価の REST API。

ベース URL

https://api.fidesorigin.com/api/v1

認証

すべての API リクエストには Authorization ヘッダーで Bearer token が必要です。

Header 
Authorization: Bearer YOUR_API_KEY

エンドポイント

GET /addresses/{address}

指定された Ethereum アドレスのリスクプロファイルを取得します。

レスポンス

JSON 
{
  "address": "0x...",
  "risk_score": 85,
  "risk_tier": "HIGH",
  "is_sanctioned": false,
  "tags": ["mixer", "high_volume"],
  "entity_name": "Unknown",
  "last_updated": "2026-07-24T09:00:00Z"
}
POST /risk-assessment

実行前にトランザクションをリスク評価のために送信します。

リクエスト本文

JSON 
{
  "from": "0x...",
  "to": "0x...",
  "amount": "1000000000000000000",
  "asset": "0x..."
}

レスポンス

JSON 
{
  "allowed": true,
  "risk_score": 15,
  "risk_tier": "LOW",
  "quarantine_required": false,
  "reason": null
}
GET /rules

すべてのアクティブなコンプライアンスルールを一覧表示します。

レスポンス

JSON 
{
  "rules": [
    {
      "id": "rule-001",
      "name": "Sanctions Screening",
      "type": "BLOCK",
      "active": true,
      "priority": 1
    }
  ]
}

エラーコード

コードステータス説明
400Bad Request無効なリクエストパラメータ
401UnauthorizedAPI キーがないか無効
404Not Foundアドレスまたはリソースが見つからない
429Rate Limitedリクエストが多すぎる
500Server Error内部サーバーエラー

Subgraph (GraphQL)

Query on-chain compliance data via The Graph subgraph.

https://api.studio.thegraph.com/query/1749664/fidesorigin-sepolia/v0.2.0

Network: Sepolia Testnet | Version: v0.2.0

Example Query

GraphQL 
{
  riskProfiles(first: 5) {
    id
    riskScore
    tier
    isSanctioned
  }
  complianceChecks(first: 5) {
    id
    from
    to
    decision
    reason
  }
}

Available Entities

  • RiskProfile — On-chain risk profiles
  • RiskProfileUpdate — Profile update history
  • ComplianceCheck — Compliance check results
  • Policy — Issuer policies
  • PolicyEvaluation — Policy evaluation records
  • QuarantineRecord — Quarantine vault records
  • TokenTransfer — Stablecoin transfer events
