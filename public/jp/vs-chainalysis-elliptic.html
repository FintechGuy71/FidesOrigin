アナリティクスを超えて —
実行グレード・コンプライアンス

Chainalysis と Elliptic は暗号資産コンプライアンスの基礎を築きました。FidesOrigin は次の段階へ進みます：執行機能を実行レイヤーに直接組み込み、トランザクションが発生する前に阻止します。

4つの根本的な違い

FidesOriginを特徴づけるもの

同じ業界でありながら、スタックの異なるレイヤーに位置します。アーキテクチャとタイミングの4つの次元が、全く異なる結果を生み出します。

タイミング

リアルタイム・インターセプション

Chainalysis と Elliptic はトランザクション確認後に調査のための分析を行います。FidesOrigin は実行前に評価し阻止するため、損失を記録するのではなく未然に防ぎます。

実行レイヤー

スマートコントラクト・ネイティブ

従来のツールはオフチェーンに存在し、人間の判断のためのデータを提供します。FidesOrigin は執行ロジックをスマートコントラクトに組み込むことで、コンプライアンスを決定的かつ回避不可能なものにします。

価格設定

トランザクション単位課金

年間SaaSサブスクリプション（5万–50万ドル）は小規模なプレイヤーを締め出します。トランザクション単位課金（10–50セント）は使用量に応じてスケールし、前払いの縛りがありません。

オープン性

MITライセンス、監査済み

クローズドソースのコンプライアンスは不透明性のリスクを生み出します。FidesOrigin のソースコードは全てMITライセンスで公開され、複数回の第三者監査を受けています。規制当局や監査人は全てのコードを検証できます。

"根本的な変化は『こういうことが起きた』から『このトランザクションは実行されない』へです。この差こそが、コンプライアンスの見せかけと真のリスク予防の間の隔たりです。"

— プロトコル設計ノート、FidesOrigin v2.4.1

ユースケース比較

各ソリューションの適した場面

どのツールも万能ではありません。適切な選択は、リスクモデル、予算、規制要件に依存します。

01

ステーブルコイン発行者がHKMAライセンスを取得する場合

香港拠点のステーブルコイン発行者は、HKMA審査官に対してリアルタイムのAMLスクリーニング、改ざん不可能な監査証跡、自動化された償還管理を実証する必要があります。

FidesOrigin

プラガブル・コンプライアンス・モジュールがステーブルコイン・コントラクトに直接組み込まれます。全ての送金が50ms以内にスクリーニングされます。全ての判断がオンチェーンに改ざん不可能に記録されます。監査証跡は暗号化されたものであり、データベースのエクスポートではありません。ある発行者はFidesOriginを使用してHKMAの原則的承認を取得しました。

Chainalysis / Elliptic

API経由でリスクデータを提供します。発行者はカスタム統合を構築し、監査ログをデータベースに保存し、規制当局に対して全てのスクリーニング呼び出しが実際に実行されたことを証明する必要があります。オンチェーン・エンフォースメントがないため、コンプライアンスは統合コードの品質に依存します。

02

DeFiプロトコルが機関投資家の資本を惹きつけたい場合

オンチェーン・レンディング・プロトコルは、資金を預ける前にコンプライアンス保証を求める機関LPを惹きつける必要があります。

FidesOrigin

プロトコル・レベルでGuardモジュールを統合。全ての借入/貸出/清算がポリシーに対してチェックされます。機関LPはオンチェーンでコンプライアンス・ロジックを検証できます。ブラックボックスではありません — ポリシーそのものがコードです。

Chainalysis / Elliptic

プロトコルはUIレベルでリスクAPIにクエリします。熟練したユーザーはUIを bypass してスマートコントラクトと直接やり取りでき、リスクチェックを発火させることはありません。コンプライアンスの見せかけであり、エンフォースメントではありません。

意思決定フレームワーク

いつ何を選ぶか

正直なガイダンス：各ソリューションには理想的なユースケースがあります。

以下が必要な場合は、FidesOriginをお選びください：

  • ✓ リアルタイム・トランザクション・インターセプション（検知だけでなく阻止）
  • ✓ 規制当局向けのオンチェーン改ざん不可能監査証跡
  • ✓ トランザクション単位課金（年間契約なし）
  • ✓ 監査・修正可能なオープンソース・インフラストラクチャ
  • ✓ ステーブルコインやRWAトークン化にライセンス級コンプライアンスが必要
  • ✓ ゼロ確認メンプール・リスク・インターセプション

以下が必要な場合は、Chainalysis / Ellipticをお選びください：

  • ✓ 法執行機関向けの捜査フォレンジクス
  • ✓ 過去のトランザクション追跡とグラフ分析
  • ✓ 脅威インテリジェンスとダークネット監視
  • ✓ 専任コンプライアンス・チームを持つ大企業
  • ✓ 年間10万ドル以上のSaaSサブスクリプション予算

多くの組織は両方を併用しています：Chainalysis/Ellipticを調査・インテリジェンス用に、FidesOriginをリアルタイム・エンフォースメント用に。
