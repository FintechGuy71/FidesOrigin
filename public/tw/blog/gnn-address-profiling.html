圖神經網路
用於鏈上地址畫像

為什麼一次只看一個地址就像試圖透過研究一棟建築來理解一座城市。FidesOrigin 的圖神經網路引擎看到的是整個圖。

2026年1月，一個錢包地址出現在我們的監控系統中，風險評分為34——遠低於80分的隔離閾值。從紙面上看，它沒問題。該地址沒有直接受到制裁打擊，交易歷史正常，沒有明顯的危險信號。傳統的基於規則的系統會放行它。

但我們的圖神經網路引擎還是標記了它。原因？這個地址距離一個已知的混幣服務只有兩跳，透過四個中間錢包連接，這四個錢包都在同一個24小時視窗內建立，並且來自同一資金來源。圖神經網路不僅看到了這個地址——它看到了它的鄰里。而這個鄰里因為關聯而被判定有罪。

三天後，該地址出現在 OFAC SDN 名單上。我們傳統的規則引擎在官方更新前完全錯過了它。圖神經網路提前捕獲了它。

這就是基於關係的風險分析的力量。也是為什麼單地址畫像在鏈上合規方面根本不足的原因。

單地址分析的侷限

傳統的鏈分析——為當今大多數合規 API 提供動力的那種——工作方式如下：從一個地址提取特徵（餘額、交易數量、年齡、已知關聯），輸入分類器，獲得風險評分。本質上是一個表格機器學習問題。每個地址都是電子表格中的一行。模型永遠看不到行之間的連接。

這種方法在區塊鏈上有三個致命弱點：

1. 對手故意利用圖結構。 複雜的攻擊者不會使用一個錢包。他們使用五十個。他們透過中間地址剝離資金。他們使用隱私池、跨鏈橋和 DeFi 協定作為洗錢層。每個單獨的地址看起來都是無辜的。模式才是訊號。表格模型對此視而不見。

2. 新地址沒有歷史。 新建立的錢包有零筆交易、零餘額和零特徵。表格模型無從下手。但圖神經網路可以從其連接推斷風險：誰資助了它？它與誰交易？它屬於哪個子圖？圖揭示了交易歷史所隱藏的資訊。

3. 風險是上下文相關的，不是固有的。 從受制裁實體接收資金的地址是有風險的。從合法交易所接收資金的同一地址則不是。風險是關係的屬性，而不僅僅是地址本身。沒有圖就無法計算它。

Chainalysis 和 Elliptic 已經建立了龐大的標記地址資料庫。他們的模型很複雜。但它們本質上仍然是表格化的：「地址X具有屬性Y，因此風險為Z。」圖是事後考慮——一種視覺化工具，而不是計算模型。

我們顛覆了這一點。在 FidesOrigin 中，圖就是模型。

鏈上圖：節點、邊和特徵

要了解圖神經網路如何用於地址畫像，我們先來定義我們正在操作的圖。

節點是錢包地址和智慧合約。每個節點都有一個特徵向量，捕獲其固有屬性：交易數量、平均交易價值、首次交易以來的時間、餘額歷史方差、合約互動多樣性等。我們從鏈上資料中提取每個節點約40個特徵。

邊代表交易。從地址A到地址B的邊表示A向B發送了資金。邊按交易價值、頻率和時間接近度加權。同一對之間的多筆交易被聚合為具有複合權重的單一邊。我們目前在以太坊、Base 和 Polygon 上追蹤約23億條邊。

節點標籤來自多個來源：OFAC 制裁名單、交易所熱/冷錢包標識、已知 DeFi 協定合約、釣魚詐騙資料庫以及我們自己的手動調查。只有極小比例的節點被標記——通常不到0.01%。挑戰在於將這些標籤透過圖傳播到未標記節點。

圖的規模：我們的生產圖目前包含約1.8億個節點和約23億條邊，從以太坊主網、Base 和 Polygon 即時更新。完整圖對於單個 GPU 來說太大，因此我們使用子圖採樣和小批量訓練。

從圖到風險評分：圖神經網路的工作原理

圖神經網路基於一個簡單但強大的理念運作：節點的表示應該是其自身特徵和其鄰居表示的函數。資訊透過圖傳播，一次一跳，網路的每一層允許模型看到鄰域更遠的地方。

我們使用受GAT（圖注意力網路）啟發的注意力機制的GraphSAGE（圖採樣與聚合）架構。以下是這種組合適用於我們的用例的原因：

GraphSAGE專為歸納學習而設計——它可以為訓練期間從未見過的節點生成嵌入。這對於鏈上合規至關重要，因為新地址每秒都在建立。我們無法每次出現新錢包時都重新訓練模型。GraphSAGE 的採樣方法讓我們能夠使用僅本地鄰域即時計算新節點的嵌入。

注意力機制（來自 GAT）讓模型學習哪些鄰居最重要。並非所有連接都平等。來自隨機地址的10美元轉帳是噪音。來自已知交易所的50萬美元轉帳是訊號。注意力權重自動從資料中學習，無需手工規則。

前向傳播的工作方式如下。對於每個節點，我們採樣固定數量的鄰居（我們使用每跳25個鄰居的2跳）。我們使用學習的聚合函式聚合鄰居特徵——在我們的情況下，來自注意力機制的學習加權平均。然後我們將聚合的鄰居表示與節點自身的特徵連接起來，並透過非線性變換傳遞。對L層重複此操作（我們使用L=3），你就有一個編碼L跳鄰域資訊的節點嵌入。

圖神經網路前向傳播（簡化版） Python / PyTorch Geometric 
import torch
import torch.nn.functional as F
from torch_geometric.nn import SAGEConv, GATConv

class RiskGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = GATConv(hidden_channels, hidden_channels, heads=4, concat=False)
        self.conv3 = SAGEConv(hidden_channels, out_channels)
        self.classifier = torch.nn.Linear(out_channels, 3)  # ALLOW, WARN, BLOCK

    def forward(self, x, edge_index, edge_attr):
        # Layer 1: SAGE aggregation, 1-hop neighbors
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 2: GAT with attention, 2-hop neighbors
        x = self.conv2(x, edge_index, edge_attr)
        x = F.elu(x)
        x = F.dropout(x, p=0.3, training=self.training)

        # Layer 3: SAGE aggregation, 3-hop neighbors
        x = self.conv3(x, edge_index)

        # Risk classification
        return self.classifier(x)

輸出是三分類（允許、警告、攔截）加上0到100的連續風險評分。風險評分使用校準的 softmax 從 logits 導出——我們在保留驗證集上使用溫度縮放來確保評分在概率上有意義。

三種圖神經網路驅動的檢測模式

圖神經網路不僅僅產生風險評分。它使表格方法無法實現的特定檢測能力成為可能。

1. 社群發現：映射混幣網路

混幣服務和 tumbler 是鏈上合規的阿基里斯之踵。它們透過聚合來自多個來源的輸入並將其重新分配到多個輸出，故意混淆資金流動。從單地址角度來看，混幣輸出地址看起來是從「合法」服務接收資金。從圖角度來看，它是一個具有特定拓撲特徵的密集連接叢集中的節點。

我們的圖神經網路學會識別這些特徵：異常高的入度和出度、與其他混幣相關地址之間的短平均路徑長度、時間聚類（狹窄時間視窗內的許多相關交易）和價值同質性（進出金額相似）。模型不需要知道混幣器的名稱。它從圖結構中學習模式。

在生產環境中，這使我們能夠識別出14個任何公共資料庫中都沒有的未知混幣服務。其中之一在被檢測到之前已處理了超過4000萬美元的交易量。

2. 異常檢測：發現女巫攻擊

鏈上背景下的女巫攻擊涉及建立許多化名身份（錢包）來操縱協定——用於空投農場、治理操縱或洗盤交易。每個單獨的錢包看起來正常。但圖神經網路看到了建立模式：數十個來自同一來源的錢包，具有相似的交易模式，從不相互互動（以避免明顯的聚類），但都在狹窄的時間視窗內透過共同的 DeFi 協定連接。

圖神經網路計算所有節點的嵌入。然後我們對這些嵌入執行 DBSCAN 聚類。正常使用者形成分散的、低密度的叢集。女巫網路形成緊密的、高密度的叢集，與合法使用者明顯分離。聚類是無監督的——我們不需要標記的女巫資料。圖結構就是訊號。

我們在2026年3月檢測到一個針對空投活動的3200個錢包的女巫農場。該農場旨在規避簡單啟發式規則（每個錢包都有「獨特」的資金來源，透過剝離鏈）。圖神經網路在嵌入空間中捕獲了共同的結構特徵。

3. 風險傳播：傳染如何擴散

也許圖神經網路最強大的能力是風險傳播。當一個新地址被新增到 OFAC SDN 名單時，圖神經網路不僅僅標記該地址。它為3跳鄰域內的每個節點重新計算風險評分。以前低風險的地址可能因為現在直接或間接連接到受制裁實體而升級為高風險。

這不是簡單的傳遞閉包。圖神經網路學習風險如何傳播：來自受制裁地址的1000萬美元轉帳是高風險。透過中間交易所三跳之外的50美元轉帳風險較低。GAT 層中的注意力權重從訓練資料中學習這些細微的傳播規則。

當 OFAC 在2026年4月更新制裁名單時，我們的系統在5分鐘內為210萬個地址重新計算了風險評分。其中，847個地址跨越了隔離閾值，並自動在風險註冊表中被標記。基於規則的系統只會捕獲直接列出的地址——23個。

即時特徵工程管道

模型的好壞取決於供給它的資料管道。我們的管道在連續迴圈中執行：

資料攝取：我們透過 WebSocket 訂閱來自多個 RPC 提供商的以太坊、Base 和 Polygon 的即時資料。新交易透過 Kafka 緩衝，按區塊號分割。我們在高峰期每秒處理約15,000筆交易。

圖建構：每筆新交易都會即時更新圖。我們在分散式鍵值儲存（ScyllaDB）中維護圖，每個節點都有鄰接表。邊權重在插入時計算：按發送者歷史平均值歸一化的價值、時間衰減因子和代幣型別（穩定幣比 meme 幣的風險權重更高）。

圖神經網路推理：每5分鐘，我們觸發批量推理作業。我們識別自上次執行以來所有已更改的節點（新交易、更新標籤或手動註釋）及其3跳鄰域。我們使用在 GPU 叢集上執行的生產圖神經網路模型計算該子圖的嵌入。平均推理時間：50萬個節點的批次約90秒。

標籤生成：圖神經網路輸出風險評分和分類。我們應用後處理規則：攔截分類且置信度>0.95的地址被標記為立即行動。警告分類且置信度>0.8的地址排隊等待人工審查。其他所有內容都與其評分一起儲存在風險資料庫中。

預言機推送：更新的風險評分被格式化為 Merkle 樹並推送到鏈上預言機合約。然後預言機更新 RiskRegistry，使新評分可用於守衛和合規引擎。從交易攝取到鏈上可用的總延遲：<7分鐘。

效能與準確性

讓我們談談數字。我們已經在生產環境中執行圖神經網路8個月了。以下是最重要的指標：

制裁地址識別：在50,000個地址的保留測試集上（包括1,200個已知制裁地址），圖神經網路在識別制裁地址方面達到了96.3%的精確率和94.7%的召回率。誤報率為0.8%——意味著99.2%的非制裁地址被正確分類為乾淨。這顯著優於我們之前的表格 XGBoost 模型，後者在同一資料集上達到了89.1%的精確率和82.4%的召回率。

混幣器檢測：在手動整理的8,500個混幣相關地址資料集上，圖神經網路達到了91.2%的 F1 分數。關鍵優勢在於檢測未知混幣器——訓練標籤中不存在的地址。在這裡，圖神經網路的歸納能力大放異彩。它透過識別結構模式而不是記憶地址來推廣到新的混幣器。

推理延遲：對於單地址查詢（我們守衛整合的常見情況），GPU 上的嵌入計算約需12毫秒，CPU 回退約需45毫秒。對於批量推理（50萬個節點），完整管道約需90秒完成。5分鐘的更新間隔意味著鏈上風險資料永遠不會超過5分鐘的陳舊度。

訓練：我們每月在完整圖上使用半監督學習重新訓練模型。模型在標記節點（制裁、交易所、已知不良行為者）上訓練，並使用圖結構將標籤傳播到未標記節點。在4個 A100 GPU 上訓練約需6小時。

為什麼這對合規很重要

鏈上金融的監管格局正在硬化。歐盟的 MiCA 框架要求「能夠檢測可疑模式的交易監控系統」。香港的穩定幣許可制度要求「持續監控客戶交易」。美國財政部明確表示，合規計畫必須「合理設計」以防止制裁違規——而「我們不知道」不是辯護理由。

僅針對靜態列表檢查地址的合規系統不是「合理設計」的。它是一個打勾清單。監管機構知道這一點。他們要求行為分析、模式檢測、關係映射。圖神經網路正好提供了這些——而且是以監管機構可以獨立驗證的審計追蹤形式。

每個圖神經網路推理結果都被記錄：輸入特徵、採樣的圖鄰域、模型版本、輸出評分和時間戳。這不是做出不透明決策的黑盒 AI。它是一個透明的、可復現的風險評估，碰巧使用神經網路進行計算。

更重要的是，圖神經網路實現了主動合規。與其對制裁名單更新做出反應（這可能比實際活動滯後數天或數週），圖神經網路在它們出現在官方名單之前就識別出風險模式。我們在1月份標記的地址——距離混幣器兩跳，透過可疑的錢包建立模式連接——三天後出現在 OFAC 名單上。圖神經網路沒有水晶球。它有圖。

對於穩定幣發行方、DeFi 協定和 RWA 平台，這意味著一個不僅讓你免於麻煩——而且讓你領先於麻煩的合規層。在一個監管行動可能關乎存亡的行業中，領先是唯一安全的地方。
