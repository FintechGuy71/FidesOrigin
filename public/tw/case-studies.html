穩定幣

GlobalPay USD — MiCA 合規穩定幣

GlobalPay 推出了一款面向歐盟市場的歐元背書的穩定幣。他們需要即時 OFAC 篩查、MiCA 儲備證明和自動化 KYC 驗證——且不引入中心化基礎設施。

FidesOrigin 的 CompliantStableCoin 基礎合約在每次鑄造、銷毀和轉帳時提供確定性篩查。策略引擎配置了 MiCA 專用規則：1:1 儲備要求、每日交易限額和合格投資者檢查。

RWA

RealT — 代幣化房地產合規

RealT 在多個司法管轄區將房地產代幣化。每處房產有不同的投資者要求：部分僅限美國合格投資者，部分需符合歐盟 MiCA，還有司法管轄區特定的 KYC。

FidesOrigin 的多策略支援允許 RealT 為每種代幣分配不同的合規規則。基於梅克爾樹的風險註冊表實現了隱私保護驗證，無需在鏈上暴露投資者資料。

// Per-token policy assignment
function assignPolicy(
    address token,
    Policy calldata policy
) external {
    policies[token] = policy;
    emit PolicyAssigned(token, policy.id);
}
智慧錢包

SafeFlow — 具備合規功能的帳戶抽象

SafeFlow 為機構用戶構建了一個 ERC-4337 智慧錢包。他們需要在 bundler 提交前對每個 userOp 進行篩查——且不增加延遲或影響帳戶抽象流程。

透過在驗證階段整合 FidesOrigin，SafeFlow 在 bundler 看到 userOp 之前篩查所有目標地址和呼叫資料。整合僅增加了不到 10ms 的驗證時間。

// Validate before bundler acceptance
function validateUserOp(
    UserOperation calldata userOp
) external override returns (uint256) {
    require(
        fides.isCompliant(userOp),
        "Non-compliant userOp"
    );
